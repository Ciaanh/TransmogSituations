Determining the active racial form (Worgen/Human or Dracthyr Dragon/Visage) for a character in a World of Warcraft addon requires checking specific auras (buffs) or character data via the WoW API, as Blizzard does not provide a single dedicated function like GetActiveForm().

Because form changes modify your character's visual model and aura states, you can track them reliably using C_UnitAuras.
1. Checking Worgen Form (Worgen / Human)

For Worgens, being in human form or worgen form is typically checked by seeing if the character currently has the "Altered Form" or related passive/buff auras, or by checking the player's race/model state. However, the most robust programmatic method in modern Lua is iterating through player auras or checking model features:

    Aura Check Approach: You can scan unit auras on "player" using C_UnitAuras.GetAuraDataBySpellName("player", "Altered Form") or checking active spell effects tied to the transformation.

    Alternatively, many addons inspect the player's active appearance or race flags, though checking for specific transformation buffs or tracking when the UNIT_AURA event fires for racial spells provides real-time accuracy.

2. Checking Dracthyr Form (Dragon / Visage)

For Dracthyr, the game handles the Visage form as an active aura effect.

    The Visage Aura: When a Dracthyr is in their humanoid Visage form, they possess a specific aura (Visage). You can check for it using C_UnitAuras:

Lua

local function IsDracthyrInVisageForm()
    -- Check for the Visage buff/aura by name or spell ID
    local aura = C_UnitAuras.GetAuraDataBySpellName("player", "Visage")
    return aura ~= nil
end

3. Recommended Event-Driven Approach

Instead of polling continuously, listen to events that trigger when forms change:

    Register for UNIT_AURA or look for combat log / spell cast success events matching Two Forms, Calm the Wolf, or Visage.

Solution 1: Use Spell IDs Instead of Names

The underlying Spell IDs for these racial forms are universal across all language clients.

    Dracthyr Visage Spell ID: 369536 (Visage)

    Worgen Altered Form / Human Form Check: Worgens use hidden auras or tracker spells depending on the exact transformation state, but checking the active spell aura via ID handles localization safely.

You can query auras by Spell ID using C_UnitAuras.GetAuraDataBySpellId:
Lua

local function IsDracthyrInVisageForm()
    -- 369536 is the universal Spell ID for Visage across all localizations
    local aura = C_UnitAuras.GetAuraDataBySpellId("player", 369536)
    return aura ~= nil
end

If you ever need to dynamically fetch details about a spell without hardcoding text, you can pull localized or unlocalized data safely via the modern API:
